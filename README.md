# WebTestOnline

PHP/MySQL online testing platform with admin dashboard, public exam links, mobile-friendly participant flow, multiple-choice, essay and Matrix/DISC questions.

## Local setup
1. Configure Apache/XAMPP and MySQL.
2. Keep environment-specific credentials out of Git.
3. Open `/admin/`.

## Public links
Set `PUBLIC_BASE_URL` for production HTTPS. Cloudflare Tunnel can be used for temporary external testing.

## Security
Do not commit credentials, runtime storage, uploaded files, backups, or update ZIPs.
